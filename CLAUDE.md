# Estúdio de vídeos com IA

Este repositório guarda skills do Claude Code em `skills/`. Elas não carregam sozinhas a partir desta pasta: precisam ser copiadas para `~/.claude/skills/` ou para o `.claude/skills/` de um projeto.

Quando a pessoa pedir para instalar, configurar ou começar a usar o estúdio ("instala as skills do estúdio", "configura o estúdio", "acabei de clonar, e agora?"), leia e siga `skills/instalar-estudio/SKILL.md`, passo a passo.

Nunca peça, leia ou digite chave de API: a pessoa faz o login em cada serviço.
